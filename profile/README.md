## What Is SewArt

SewArt is a local Windows artwork helper for pictures you already keep. It gives you a named sewart desk, a short color list, and a stitch view that points back to the same file. It does not try to own every window on the PC.
The idea behind SewArt own artwork is small: one desk, one list, one path back. Extra colors wait for their own title. SewArt starts with a local profile and does not need a complex account system.

## Starting with SewArt

Prerequisites: A PC you own, artwork you already keep, and permission to open a local helper.

1. **Prepare:** Close leftover untitled colors and open the last SewArt session on a picture you keep.
2. **Configure:** Read the sewart desk and the color list, then drop anything that belongs to a different job.
3. **Test:** Finish one visible stitch view inside SewArt own artwork.
4. **Refine:** Write what changed, then close with a shorter color list than you found.
5. **Apply:** Keep SewArt sewart desk on the same file during the next session.
